Minha engenharia de software

asasvirtuais — Framework open-source · Criador

2025 – atual

github.com/asasvirtuais/asasvirtuais-framework · publicado no npm

  • Uma interface CRUD (find, list, create, update, remove) roteada para um middleware por tabela, que concentra toda regra de leitura, validação prévia e efeito colateral daquela tabela.
  • Um schema zod por tabela que serve como tipo TypeScript, validação e campos de formulário; formulários gravam num índice compartilhado de linhas em memória, então a interface nunca guarda cópias desatualizadas.
  • Backends plugáveis: REST, IndexedDB (Dexie.js), memória, Airtable, Prisma. Inclui um AGENTS.md que diz a qualquer agente de código onde cada parte do código vai.
